## Прод-заметки (стадия 2)

- Секреты форм: **только** через `apply-form-secrets.yml` (dispatch), не руками. Идемпотентен, пересинхронит блок. `SMTP_PASS` опционален (нет секрета → SMTP-блок не пишется).
- ⚠️ Пароль приложения Яндекса создавать **под аккаунтом ящика** `valstan@valstan.ru` — иначе `535`, неотличимая от неверного пароля.
- Порядок ручного вмешательства в прод-БД: `setup-prod-stage2.yml` с `force_restore=true` **сносит контент** — только осознанно.
- Будущие изменения схемы Payload → миграция + применение на проде ДО деплоя (guard `#017`, паттерн `apply-migration.yml` Сабантуя).
- ISR-паттерн: свежие страницы v2 после деплоя показывают пустые «Новости»/«FAQ» (CI собирает с пустой БД) — наполняются при первой ревалидации с прод-БД, как sitemap.
- Локальная разработка требует Postgres: `.env.example` → `.env`; после добавления коллекции — `corepack pnpm payload run src/seed/pushSchema.ts`.
