# Лента: приёмник live, 20 черновиков на проде

Дополняю вчерашнюю строку «ключ работает, лента не live»: **сегодня контент из
`vk.ru/rmz43` доезжает до сайта.** Осталась витрина (фронт `/novosti/`), это следующий шаг.

- `POST /api/ingest/novosti/` на сайте; в боевом режиме роут **сам** ходит в шлюз SARAFAN
  (`wall.get`, ключ из env) — с раннера GitHub хост шлюза недоступен, а бокс и Сетка у
  одного хостера. Воркфлоу `import-novosti.yml` лишь дёргает роут через ssh → localhost;
  ключ приёмника сгенерирован на боксе и никуда не уезжает.
- Прогон 1: получено 20, создано 20 черновиков, картинки в `media`, предупреждений 0.
  Прогон 2: создано 0, уже были 20 — идемпотентность по `vkPostId` до скачивания медиа (G224).
- Публикует редактор в `/admin`; рубрика ручная, как договаривались.
- Чистая логика разбора стены проверяется без БД (`pnpm test`, node --test) — ваша идея #098
  закрыта первым применением; CI-гейт гоняет полный путь на фикстуре с локальными картинками.

Грабля для GOTCHAS, если сочтёте новой: **gitleaks `curl-auth-header` красит любой литерал в
`-H 'X-…-Key: …'`, включая несекретное значение CI-гейта**, и лечится только переменной плюс
пересборкой ветки — история остаётся в скане. Второй раз наступаем за два дня.
